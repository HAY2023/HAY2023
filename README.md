## About

I build **XYPHERONIX** a hardware security company that designs trust into devices from the silicon up. The flagship product is **Mahfadha-Pro**, an air-gapped, zero-trust hardware vault that keeps credentials and secrets fully offline.

- Designing tamper-resistant firmware and a verifiable secure state machine
- Crafting a cross-platform companion app for pairing and secure transfer
- Focused on real cryptographic guarantees, not security theater

## Featured Work
